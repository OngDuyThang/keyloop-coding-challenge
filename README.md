## Scenario

This project implements **Scenario D: The Unified Document Viewer** from the Keyloop Technical Assessment.

The system provides a unified interface for searching vehicle-related documents using a VIN and aggregates documents from two mocked dealership systems:

* Sales System
* Service System

## AI-SDLC

This project was developed using a three-phase AI Software Development Lifecycle:

1. **Inception**

   * Requirements refinement
   * Ambiguity resolution
   * Assumptions
   * Architecture and technical decisions

2. **Construction**

   * Implementation
   * Unit tests
   * Integration tests where appropriate
   * Documentation

3. **Build & Test**

   * Build validation
   * Test execution
   * Coverage
   * HTML coverage report
   * Debugging and re-validation

See `docs/AI-SDLC.md` for the complete process.

## AI Collaboration Narrative

The project uses GenAI as an engineering collaborator.

The development process focuses on directing the AI, validating its output, identifying problems, and retaining human ownership of the final technical decisions and implementation.

The final narrative will document:

* How requirements were refined with AI
* How architectural decisions were made
* How AI was directed during implementation
* How generated code was reviewed
* How tests were used to validate the implementation
* Problems discovered during Build & Test
* How those problems were corrected
* How the final implementation was verified
