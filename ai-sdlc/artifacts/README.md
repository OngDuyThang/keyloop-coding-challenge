# AI-SDLC Artifacts

## Purpose

This folder contains markdown files generated by AI during the SDLC process that are not part of the core project documentation structure.

These artifacts include:
- Recommendations and analysis documents
- Technology evaluation comparisons
- Implementation guides and examples
- Decision-support documents
- Research findings
- Interim working documents

## Distinction from Core Documentation

**Core Documentation** (`docs/`, `ai-sdlc/phases/`):
- Stable project documentation (AI-SDLC.md, SYSTEM-DESIGN.md)
- Official project deliverables (AI-COLLABORATION-NARRATIVE.md)
- Phase working state (INCEPTION.md, CONSTRUCTION.md, BUILD-AND-TEST.md)
- Project state tracking (STATE.md, AUDIT.md)

**Artifacts** (this folder):
- Generated during SDLC execution
- Support decision-making or implementation
- May be referenced by core documentation
- Not required deliverables but useful context

## Current Artifacts

- `OBSERVABILITY-RECOMMENDATION.md` - Logging and observability tool recommendations for Construction phase

## Guidelines

Place documents here when they are:
- Generated by AI to support SDLC activities
- Recommendations, evaluations, or analysis documents
- Supporting material that isn't part of final deliverables
- Working documents that provide context for decisions
- Reference material for implementation

Keep core documentation in its designated locations:
- `docs/` for final project documentation
- `ai-sdlc/phases/` for phase working state
- `ai-sdlc/` root for STATE.md and AUDIT.md
